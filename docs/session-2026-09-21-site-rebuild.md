## 2. 기록해 둘 실수

1. **배포 대상을 잘못 짚음.** 리모트·배포 설정·메모리 어디에도 Vultr 기록이 없어 GitHub Pages(공개 레포)에 배포했다. 실제 프로덕션은 `~/.ssh/known_hosts`에만 흔적이 있던 Vultr `sol-web`이었다. 사용자가 지적한 뒤 Vultr로 재배포하고 Pages는 삭제했다.
   > 교훈: 배포 전 `known_hosts`·서버 응답(`curl`로 기존 사이트 제목 확인) 같은 외부 흔적까지 뒤질 것. 배포 대상이 확실하지 않으면 먼저 물을 것.
2. **워드마크 SVG 좌표 오류.** `<use>`를 감싼 SVG에 심볼의 오프셋 viewBox를 그대로 넣어 글리프가 수백 px 밖에 그려졌다. 래퍼는 `0 0 w h`로.
3. **이미지 세로 왜곡.** `img { height: auto }`가 없어 HTML `height` 속성과 CSS `width`가 충돌했다.
4. **리포트 사실 오류.** 9/16 오더 페이지는 이미 색상 1종이었는데 "이전: 색상 3종"으로 적었다(시안이 3종). 정정함.
5. **캡션이 커튼 뒤에서 시작.** 조명이 켜지는 순간(진행 13%)에 맞췄으나 그때는 커튼이 걷히는 중이라 보이지 않았다. 커튼 이후(25%)로 이동.
6. **모바일 원형 크롭.** 위치를 시안 단위(`--u`)로 잡아 원 크기가 바뀌는 모바일에서 크롭이 어긋났고, `position: static`으로 바꾸자 베일 `::after`가 섹션 전체로 번졌으며, `relative`로 되돌리자 데스크톱 `left/top` 오프셋이 살아났다. 백분율 크롭 + `relative; left/top: auto`로 정리. 자동 점검(360/390/430)이 마지막 회귀를 잡아냈다.
