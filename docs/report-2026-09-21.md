## 2. 2차 요청 반영 내역

- **제품 소개 화살표(시안 11–13p)**: 홈의 제품 소개 구간을 3화면 길이로 고정하고, 스크롤에 따라 `$380 Pre-Order`에서 ORDER 메뉴로, 이어서 `Discover More About Sol`에서 DEVICE 메뉴로 화살표가 한 번씩 그려집니다. 화살표는 시안의 벡터를 그대로 사용하며 시작점에서 목표점까지 서서히 나타나고, 도착하면 해당 메뉴가 강조됩니다.
- **DEVICE 1 / DEVICE 2 비교**: 메뉴에 두 버전을 한 줄로 두었습니다.
  - DEVICE 1: 시안을 화면 단위 섹션으로 구성한 현재 디자인.
  - DEVICE 2: 시안 26–40p 전체를 하나의 고정 화면으로 두고, 가운데 제품 렌더가 스크롤에 따라 교체·이동(패럴랙스)하며 텍스트가 시안 위치에서 나타났다 사라지는 버전. 시안의 768pt 구도를 화면 세로 중앙에 배치.
- **라이브러리 검색(시안 43p)**: 돋보기를 누르면 돋보기가 오른쪽으로 이동하면서 검은 언더바와 검색창이 나타납니다. 포커스 시에도 언더바는 검정을 유지하고, 입력하면 시나리오 목록이 필터링됩니다.
- **임시 문구 구분**: 시안에 없어서 임의로 채운 라이브러리 시나리오 이름은 취소선으로 표시했습니다(실제 문구 확정 시 교체).
- **한 화면 페이지 정리**: Wiki·Careers는 푸터를 화면 하단에 고정하고, Order는 시안대로 한 화면 구성이라 푸터를 제외해 불필요한 여분 스크롤을 없앴습니다.

## 4. 모바일 스크롤 속도 평가(피드백 3번, 미적용)

원인은 프레임레이트가 아니라 스크롤 거리 대비 프레임 매핑입니다. 프레임 수를 늘려도 체감 속도는 그대로이고 끊김만 줄어듭니다.

| 환경 | 스크럽 길이 | 프레임당 스크롤 거리 |
|---|---|---|
| 데스크톱 1440×900 | 3600px | 30px |
| 모바일 390×844 | 3376px | 28px |

모바일에서 한 번 플릭하면 관성으로 1000–2000px가 0.4초 안에 지나가 35–70프레임이 순식간에 넘어갑니다. **권장안:** 터치 기기에서만 스크럽 길이를 약 2배(4화면 → 7~8화면)로 늘리고, 스크롤 스무딩을 조금 더 주는 것. 설정값 두 곳만 바꾸면 되며 결정 주시면 바로 적용 가능합니다.

- 정적 사이트(HTML/CSS/JS), GSAP ScrollTrigger + Lenis, 빌드 도구 없음
- 시안 서체 Satoshi 셀프호스팅, 워드마크·제품 렌더는 시안 PDF에서 직접 추출
